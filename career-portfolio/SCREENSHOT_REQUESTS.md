# 추가로 받으면 PDF에 넣을 화면

실거래·모의 주문 실행은 하지 않는다. 읽기 전용 화면만 필요하다. 계좌번호, 토큰, 이메일 비밀번호, API 키는 가린 뒤 전달한다.

## 웹 포트폴리오

이번 PDF에 이미 있는 화면: 메인, 로그인(빈 폼), 상품 목록, 상품 상세, 비회원 장바구니 1건, 체크아웃(100원 안내 문구), 커뮤니티 목록, 홈 프로젝트 카드.

아직 없는 화면:

1. 관리자 상품 목록·수정 (`/admin/shop`)
2. 관리자 이력 또는 프로젝트 수정 (`/admin/resume`, `/admin/projects`)
3. 로그인 이후 서버 장바구니
4. 100원 테스트 결제의 취소 완료 화면 (`/order_success` 또는 `/payment/success`)
5. 인증 실패·권한 실패가 보이는 화면이 있으면 그 메시지

관리자 화면은 이 환경에서 비밀번호를 브라우저에 입력하지 못해 캡처하지 못했다.

## 자동매매

서버를 띄우거나 KIS 주문을 호출하지 않았다. 기존 PAPER 데이터로 읽기만 하는 화면이 필요하다.

1. 대시보드
2. PAPER 계좌 연결·검증 화면. 계좌번호는 마스킹
3. 조건식 관리
4. 주문·체결 목록에서 대기, 미확인, 체결이 함께 보이는 상태
5. 거래 불가·경고 문구가 있는 화면

## AI 에이전트

`KimSunWooo/Auto_Trading_AI_Agent`는 인증 없이 열리지 않았다. 비공개라면 공개할 범위(README, 계약, 테스트 이름만 또는 구조 설명)를 정한 뒤 인증을 요청한다. 승인 전에는 저장소 내부를 PDF에 넣지 않는다.

## 넣지 않을 것

- 실계좌 주문 실행 화면
- API 키, 쿠키, 토큰, 비밀번호가 보이는 개발자 도구
- 측정 원본이 없는 성능 그래프를 완성 결과처럼 만든 이미지
